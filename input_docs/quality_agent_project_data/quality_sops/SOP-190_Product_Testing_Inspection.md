# SOP-190: Product Testing and Inspection Procedures

**ISO 9001:2015 Reference:** Clause 8.6 – Release of Products and Services

## Purpose
Defines the requirements for functional testing, in-process inspection, and final release testing to ensure only conforming product is shipped.

## Scope
Applies to all in-process and final test stations across wafer probe, package test, burn-in, and final functional test.

## Procedure
1. **Test Program Control**: Test programs must be version-controlled, and all test stations running a given product must use an identical, currently-approved test program version. A version mismatch across stations is a reportable non-conformance.
2. **Repeatability Checks**: Units yielding inconsistent pass/fail results on retest within a short window (e.g., under 24 hours) must be flagged for test equipment investigation before further product is released from that station.
3. **Environmental Chamber Uniformity**: Burn-in and environmental test chambers must maintain temperature/humidity uniformity within specification across all tray positions, verified per the calibration schedule in SOP-130.
4. **Test Escapes**: Any defect discovered in the field or by a customer that should have been caught by an existing test step is classified as a test escape and automatically triggers a CAPA per SOP-114, including a gap analysis of the test coverage.
5. **Sampling and Full Test Requirements**: Final release testing must be 100% functional test for shippable product; sampling plans may only be used for in-process monitoring steps, never for final release disposition.
6. **Disposition Hold**: Product may not be released to shipping until all required test records are complete, reviewed, and electronically signed off by Quality.
